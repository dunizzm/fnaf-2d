# Five Nights at Freddy’s — неофициальная 2D-версия

Браузерная фан-игра с оригинальными изображениями FNAF 1 и новой реализацией логики. Это не точная копия оригинального движка и его баланса.

Пять ночей, своя ночь 0–20, 11 камер, двери, свет, энергия, анимированные скримеры, сохранение прогресса. Каждая ночь длится ровно 6 минут активной игры. Пауза не учитывается.

Управление: A/D — двери, Q/E — свет, пробел — монитор, Esc — пауза, M — звук. Монитор открывается и закрывается при повторном наведении на нижнюю полосу. На сенсорных устройствах — нажатием. Для обзора офиса перемещайте курсор к краям. Нос Фредди на плакате пищит при нажатии.

Сборка автономного файла: установите Python 3 и запустите `python bundle.py`. Результат появится в папке `outputs/`.

Файл FNAF-2D.html запускается двойным щелчком в современном браузере; все необходимые изображения, шрифт и звуки встроены. Интернет для игры не требуется. Звук активируется после нажатия «Новая игра». Сохранение в локальных файлах зависит от браузера.

Исходный код сайта находится в папке `dist/`. Для локального запуска: python -m http.server 4317 --directory dist, затем http://localhost:4317. Проверки: node engine.test.cjs и node balance.test.cjs.

Персонажи, графика и исходные звуки FNAF принадлежат Scott Cawthon. Набор изображений и звуков: https://github.com/wellsousaaa/Five-Nights-at-Freddys-Web/tree/main/src/media . Код игровой логики и интерфейса написан отдельно. Металлические шаги и писк носа синтезируются. Шрифт Consolas — Microsoft; файл-источник: https://github.com/MemeCrafters/meme-generator/blob/main/resources/fonts/consola.ttf .

## Настольные версии

Готовые приложения для Windows x64, Linux x64, macOS Intel и Apple Silicon доступны в [Releases](https://github.com/dunizzm/fnaf-2d/releases). Интернет во время игры не требуется. Эти сборки не подписаны сертификатами Microsoft/Apple.

Для разработки: Node.js 24, `npm ci`, затем `npm start`. Проверки: `npm test`. Нативная сборка на текущей ОС: `npm run build:desktop` (Linux также требует `xvfb-run` для автоматической проверки запуска). Готовый архив появится в `release/`.

Публикация тега `v*` запускает сборку и проверку приложений на четырёх нативных GitHub Actions runners. Release публикуется только после успешного завершения всех четырёх сборок. Для будущих релизов номер версии и имена файлов в release notes нужно обновить перед тегом.

## iOS

Проект для iPhone/iPad на iOS 16+ находится в `ios/`. iOS использует собственную оболочку SwiftUI / WKWebView; Electron в неё не входит. Для сборки нужны Mac, Xcode с iOS Simulator, Python 3 и XcodeGen (`brew install xcodegen`). Команда: `bash scripts/build-ios.sh`.

Сборки iOS публикуются отдельно по тегам `ios-v*`: неподписанный IPA для устройства и универсальный `.app` для симулятора (Intel / Apple Silicon). **Неподписанный IPA нельзя установить на iPhone напрямую: нужна подпись своим Apple-аккаунтом.** Инструкции и ограничения: [ios/RELEASE.md](ios/RELEASE.md).
